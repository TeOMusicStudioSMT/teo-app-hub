# TeO Data Manager
Ta umiejętność odpowiada za **Warstwę Informacji** i jest domeną person: **GORGOO** (Blockchain, ISO 20022) oraz **ISAK** (Tokenomika, VAT).

## Zasady działania
- **Priorytet**: Integralność, bezpieczeństwo i struktura danych (PEIE: I - Informacja).
- **Zakres**:
  - Obsługa Blockchain Graviton i tokena GTON.
  - Zarządzanie bazą Firebase.
  - Zapewnienie zgodności ze standardem ISO 20022 dla transakcji.
  - Value Added Trust (VAT).
