### 🛠️ Specyfikacja Techniczna Modułu:

1. **Widok Siebie (`WebRTC Engine`)**:
   - Przechwytywanie obrazu z fizycznej kamery (1280x720 @ 60 FPS).

2. **AI Audio Orb (`Web Audio API Analyser`)**:
   - Bezpośrednia analiza pakietów PCM przesyłanych strumieniowo z API Gemini 3.6 / OpenAI Realtime.
   - Płynne renderowanie natężenia myśli na `HTML5 Canvas` (Glow Aura, Central Core, Waveform Spectrum Ring).

3. **Gość Live (`RTC Remote Peer Slot`)**:
   - Dedykowany slot w strukturze UI na przyjmowanie strumieni wideo od zdalnych prelegentów.
   - Indykatory statusu połączenia na żywo.

4. **Baza Broadcastu RTMP (`Offscreen Canvas 1080p 60FPS -> WebSocket Ingest`)**:
   - Niewidoczny kompozytor łączący strumień lokalny, strumień gościa oraz wizualizację Orba AI.
   - Przekazywanie klatek wlocie co 250ms przez MediaRecorder + WebSocket bezpośrednio do serwera przekaźnikowego (RTMP / YouTube Live API).

5. **Dynamic Grid Layout**:
   - Dynamiczny mikser układów wspierający tryby: `GRID` (50/50), `FOCUS_SELF` (Ja + PiP), `FOCUS_GUEST` (Gość + PiP), `FOCUS_ORB` (Scena AI).
